#+TITLE: EMatrix
#+AUTHOR: Zi Liang

EMatrix is a restrained dark theme for Emacs.  It uses a neutral graphite
canvas, soft high-contrast text, and a compact semantic accent palette.  The
theme is intended for long programming, research-writing, and mixed Latin/CJK
sessions rather than a decorative terminal aesthetic.

* Design Principles

- Neutral text carries content.  Accent colors carry meaning.
- Background elevation distinguishes windows and popups without visible boxes.
- Comments remain readable instead of fading into the background.
- Warnings, errors, selections, and diffs are distinct under prolonged use.
- Org, Markdown, and LaTeX share one document hierarchy.
- Package faces reuse the same semantic colors instead of inventing local ones.

* Installation

** package-vc-install (Emacs 29+)

#+begin_src emacs-lisp
(unless (package-installed-p 'ematrix)
  (package-vc-install "https://github.com/liangzid/ematrix"))
#+end_src

** use-package

#+begin_src emacs-lisp
(use-package ematrix
  :vc (:url "https://github.com/liangzid/ematrix"
       :rev :newest)
  :config
  (ematrix-enable))
#+end_src

** Manual

#+begin_src bash
git clone https://github.com/liangzid/ematrix ~/.emacs.d/elpa/ematrix
#+end_src

#+begin_src emacs-lisp
(add-to-list 'load-path "~/.emacs.d/elpa/ematrix")
(require 'ematrix)
(ematrix-enable)
#+end_src

* Typography

EMatrix selects the first installed monospace family from this stack:

1. Maple Mono
2. JetBrainsMono Nerd Font Mono
3. IBM Plex Mono
4. Cascadia Code
5. Iosevka
6. Fira Code

The default size is 14 points.  Noto Sans CJK SC is used for CJK characters,
and a neutral sans-serif stack is assigned to =variable-pitch=.

Customize the font before enabling the theme:

#+begin_src emacs-lisp
(setq ematrix-default-font "Maple Mono"
      ematrix-default-font-size 14
      ematrix-cjk-font "Noto Sans CJK SC")
(ematrix-enable)
#+end_src

=ematrix-set-font= updates existing graphical frames and the default for new
frames.  =ematrix-apply-font-to-frame= can be used by a custom frame hook.

* Face Coverage

- Emacs interface, syntax, search, widgets, tabs, and line numbers
- Company, Ivy, Vertico, Orderless, Marginalia, and Which Key
- Org, Org Agenda, Org Habit, Markdown, LaTeX, and AUCTeX
- Dired and Neotree
- Diff, Ediff, Magit, and Git Gutter
- Flymake, Flycheck, compilation, grep, xref, Eglot, and Citre
- Doom Modeline, Evil, Winum, Rainbow Delimiters, and indentation guides
- Eshell, Term, ANSI colors, Yasnippet, SLY, CIDER, and Telega
